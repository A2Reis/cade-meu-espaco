Onde o espaço costuma se esconder
  • C:\hiberfil.sys

    Arquivo de hibernação, mais ou menos do tamanho da memória RAM. Se você não usa hibernar: powercfg.exe /hibernate off num prompt como administrador.

  • C:\Windows\WinSxS

    Componentes do Windows. O tamanho engana: muitos arquivos são links físicos contados mais de uma vez. Nunca apague na mão; use Dism.exe /Online /Cleanup-Image /StartComponentCleanup.

  • ext4.vhdx

    Disco virtual do Docker Desktop (em %LOCALAPPDATA%\Docker\wsl) e de cada distro do WSL. Cresce e não encolhe sozinho.

  • npm-cache e navegador

    Caches em %LOCALAPPDATA%\npm-cache e no User Data do Chrome e do Edge. npm cache clean --force esvazia o do npm; o do navegador se limpa dentro dele.

  • Downloads

    Instaladores, ISOs e zips esquecidos. A aba "Maiores arquivos" acha rápido.

  • Windows.old e Windows Update

    Instalação anterior e cache de atualização (SoftwareDistribution\Download). Limpe com a Limpeza de Disco (cleanmgr) ou o Sensor de Armazenamento.
